# Adaptive Systems

Adaptive Systems explores how machine-learning systems can remain reliable in changing environments and autonomously investigate abnormal system behavior.

The project starts with multivariate time-series anomaly detection and progressively extends the system with distribution-drift monitoring, adaptive model updates, and a tool-using AI agent for incident investigation.

## Objective

The project studies two main questions:

1. How does an anomaly-detection model behave when the underlying data distribution changes?
2. Can an AI agent investigate detected anomalies and produce evidence-based diagnoses using system data and analytical tools?
